# 02 — Interface

Đây là nhóm giao diện người dùng.

- `../client/src/App.tsx`: định tuyến và khung ứng dụng.
- `../client/src/pages/Home.tsx`: giao diện chính.
- `../client/src/legacy.html`: giao diện PHP legacy.
- `../client/src/legacy-source.js`: logic frontend legacy.
- `../client/src/index.css`: style toàn cục.
- `../client/src/components/`: component dùng chung.
- `../client/public/`: PWA manifest, service worker và icon.

**Lưu ý:** thư mục `client/` giữ nguyên vị trí để Vite build và các alias `@/` tiếp tục hoạt động bình thường.
