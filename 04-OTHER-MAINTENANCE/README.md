# 04 — Other / Maintenance

Nhóm này chứa tài liệu kỹ thuật, script kiểm tra, script chuyển đổi asset và ghi chú phát triển. Các file này không được import bởi runtime production.

- `docs/`: báo cáo, ghi chú, kế hoạch và tài liệu kiểm tra.
- `scripts/`: script smoke test, so sánh source, xử lý asset và trích xuất legacy.

Các thư mục runtime chính `client/`, `server/`, `drizzle/` và các file cấu hình root vẫn giữ vị trí cũ để bảo toàn tương thích.
